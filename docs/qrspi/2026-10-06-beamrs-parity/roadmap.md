# Roadmap

1. Define the Beam domain and validate the model with failing tests.
2. Add PostgreSQL migrations for users, frequencies, rays, and prisms.
3. Implement repository methods for feed queries and prism toggling.
4. Expose REST endpoints with correct HTTP semantics.
5. Implement shared Leptos components and hydrate them from a Rust/WASM bundle.
6. Move identity, navigation, forms, API calls, prism state, and Canvas behavior into Rust.
7. Validate SSR and hydration targets, production cargo-leptos output, Docker, and PostgreSQL flows.
8. Publish the change as a PR.
