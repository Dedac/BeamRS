# Research note Q-01

## Evidence

- `Beam.Data/BeamContext.cs` defines `User`, `Frequency`, `Ray`, and `Prism` with the expected relationships.
- `Beam.Server/Controllers/UserController.cs` exposes get-or-create-by-username behavior.
- `Beam.Server/Controllers/PrismController.cs` shows prism add/remove with per-frequency feed refresh.

## Findings

- Ray authors are optional in the data model (`UserId?`) but effectively behave as anonymous posts until a user is assigned.
- A `Prism` is a user-to-ray relationship with uniqueness semantics implied by the controller logic.
- Feed queries include user and prism data in one aggregate view.
